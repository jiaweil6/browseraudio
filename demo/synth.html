Play a NumPy synth live

keyboard(render, sample_rate) turns your computer keyboard into an instrument. You design the sound in NumPy; the page plays it in real time.

This page runs a real in-browser Python kernel (thebe + Pyodide) with the actual browseraudio package — so the cells below are the genuine API, just like JupyterLite / thebe. The cells are editable; the first Run downloads the runtime (~25 MB), so give it a moment. Reload to reset.

01

Design a sound, then play it

A function from frequency to samples — here a decaying sine "pluck". Python renders it once for every note the keyboard can reach, then hands the bank to the page. Click the keyboard, then play: A S D F G H J K L ; are the white keys, W E T Y U O P the black keys, and Z / X shift the octave.

python
import numpy as np
from browseraudio import keyboard, play

sr = 22050
t = np.arange(sr) / sr                  # one second

def pluck(freq):
    return np.sin(2*np.pi*freq*t) * np.exp(-4*t)

kb = keyboard(pluck, sr)

Your key presses never wait on Python: the sound is already in the page, so notes start as fast as the browser's audio output allows. Python hears about them afterwards, as kb.events.

02

A wavetable with an envelope

Or give one cycle of a waveform: the page loops it at any pitch and shapes each note with an ADSR envelope, so notes sustain for as long as you hold the key.

python
cycle = np.linspace(-1, 1, 256)        # one sawtooth cycle
kb = keyboard(wavetable=0.5*cycle,
              attack=0.02, decay=0.2, sustain=0.6, release=0.4)
03

Replay your performance

Play something above first. kb.render() re-synthesises exactly what you played, offline, as a NumPy array you can analyse, edit, or play back.

python
print(len(kb.events), "note events")
play(kb.render(), kb.sample_rate)
